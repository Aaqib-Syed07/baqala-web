# 🛒 Baqala Web

> A premium, modern web storefront for a neighborhood supermarket — offering groceries, dairy, bakery, and homeneeds with a stunning glassmorphism UI.

## ✨ Features

- 🎨 **Glassmorphism Design** — Modern dark UI with ambient glows, blur effects, and smooth micro-animations
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop viewports
- 💬 **WhatsApp Integration** — Direct quick-links for stock inquiries, bulk quotes, and curbside pickup
- ⏱️ **Live Countdown Timer** — Weekly offers section with a real-time countdown
- 🔍 **SEO-Friendly** — Proper meta tags, semantic HTML5, and heading hierarchy
- ⚡ **No Dependencies** — Pure HTML, CSS, and Vanilla JavaScript — no frameworks, no build tools

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Aaqib-Syed07/baqala-web.git
   cd baqala-web
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in any browser
   open index.html
   ```

3. **Customize**
   - Edit WhatsApp number in `index.html` (replace `919999999999` with your number)
   - Replace images in the `assets/` folder with your store photos
   - Update store address, hours, and email in the contact section
